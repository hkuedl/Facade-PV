# Facade-PV

This repository contains the reproducibility code for the manuscript
“Synergistic Deployment of Rooftop and Facade Photovoltaics Advances
Cost-effective Building Decarbonization in China's Large Cities.”

The revised workflow covers 102 large Chinese cities and incorporates the
appeal and major-revision updates: land-use-informed grid load composition,
an RPV 35% / FPV 70% main installation case, updated 2030–2050 planning, and
the revised main-text figures.

## Software

- Python 3.10 or later is recommended.
- QGIS 3.36.3 with the [UMEP](https://umep-docs.readthedocs.io/en/latest/index.html)
  plugin is required only to repeat the original solar-radiation simulations.
- A Pyomo-compatible optimization solver is required for
  `Multi_period_planning.py`. The manuscript calculations used Gurobi.
  Configure the solver and its license outside the repository.

Core Python packages include `numpy`, `pandas`, `scipy`,
`scikit-learn`, `scikit-learn-extra`, `pyomo`, `matplotlib`,
`geopandas`, `shapely`, `fiona`, `pyproj`, `xgboost`, and `shap`.
Figure generation additionally uses `frykit`, `geopy`, `openpyxl`, and
`tables` (PyTables).

## Data

The public inputs and prepared outputs are available from
[Baidu Netdisk](https://pan.baidu.com/s/1nz6OqH5hKpRSR72fxIoMdQ?pwd=jx8f)
(access code: `jx8f`).

Download the `##Data` directory into the repository root:

```text
Facade-PV/
├── #Codes/
└── ##Data/
    ├── Evaluation/
    │   ├── UMEP_input/
    │   ├── Sampled_input_output/
    │   ├── Regression_model/
    │   ├── All_input/
    │   └── All_output/
    └── Optimization/
        ├── Electricity_price/
        ├── Loads/
        │   └── Revised_Loads/
        ├── Other_parameters/
        ├── Fig_input_data/
        └── Appeal_Opt_results/        # generated by the planning script
```

If the data are stored elsewhere, set `FPV_DATA_ROOT` to the `##Data`
directory. Individual paths can also be overridden with the environment
variables documented at the top of the relevant scripts.

The large `All_output/Power1.zip`–`Power6.zip` archives remain the
baseline predictions generated with 90% availability of the filtered facade
AOI. They do not need to be regenerated for the revision. The revised
sensitivity tables and planning code scale the grid-level baseline to the
saved main case: 35% rooftop availability and 70% of the filtered facade AOI
(42.2% of total facade surface).

## Reproduction order

Run commands from the repository root.

1. Optional evaluation/model reproduction:

   ```text
   cd #Codes/Evaluation
   ```

2. Generate the revised land-use-informed annual loads:

   ```text
   python #Codes/Optimization/Load_generate.py
   ```

3. Run the 2030–2050 planning model. The default processes all 102 cities;
   city-index ranges allow distributed runs:

   ```text
   python #Codes/Optimization/Multi_period_planning.py --city-start 0 --city-end 102
   ```

4. Generate revised figures:

   ```text
   python #Codes/Figures/Fig_new_1bc.py
   python #Codes/Figures/Fig_new_2.py
   python #Codes/Figures/Fig_new_3.py
   python #Codes/Figures/Fig_new_4.py
   python #Codes/Figures/Fig_new_5.py
   python #Codes/Figures/Fig_new_6.py
   ```

`Fig_new_1bc.py`, `Fig_new_3.py`, and `Fig_new_4.py` use compact
revision caches distributed in `Fig_input_data`. Their raw-result
recalculation paths remain available when all 102 optimization MAT files are
present. Figures 5–6 use the revised Beijing, Wuhan, and Shenzhen MAT files
distributed in `Fig_input_data/Appeal_Opt_results`.

See the subdirectory readme files for file-level details.
